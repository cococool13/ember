# Ember 0.8.0

- New dark mode look in the menu-bar panel with dark coal and warm ash colours. Ember orange now shows only at evening and night.
- Setup now opens with large type and the Ember mark as a turning chrome lens. With Reduce Motion on, it shows one still frame.
- New About page in the Ember window, and a new header in the license window.
- Display warming and dimming haven't changed. The dial, scrubbing to preview, night strengths, Pause and VoiceOver work as before.
