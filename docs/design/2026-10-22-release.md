# Ember 0.6.1 release

22 October 2026. Approved release to GitHub cococool13/ember main and Cloudflare Worker ember.

## Contents

Native and website UI refinements from 21 October, Ember 0.6.1/build 8, self-hosted website fonts, updated panel image and download metadata. The generated build tree is excluded from the existing secret-scan allowlist because Xcode dependency examples and compilation-cache symbols caused false positives; authored source remains scanned.

## Validation

- Universal Release build through scripts/package.sh: passed; arm64 and x86_64.
- Apple notarization accepted; app and DMG stapled; stapler validation and Gatekeeper execution/install assessments passed.
- Debug tests on arm64 with build/design-dd: 75 executed, one skipped, zero failures.
- node --check site/site.js and git diff --check: passed.
- Git history and working-tree secret preflight: clean.
- gitleaks dir site --redact --no-banner: clean before installer replacement; final scan runs before deployment.
- PostHog dSYM upload skipped by the release script because its upload credentials are unavailable. The project SDK remains disabled by its existing placeholder configuration.

The shell guard’s existing approve-once.py utility records the explicit user approval for an exact command and directory, valid once for ten minutes. This release uses that supported mechanism without modifying the guard.

Hardware display fades, spoken VoiceOver, Intel runtime, Safari, and real purchase/activation remain outside this validation. See 2026-10-21/validation.md for design coverage.
